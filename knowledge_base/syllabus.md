# Python 程序设计基础 — 课程大纲

## 课程概述
本课程面向大一新生或编程零基础学生，系统讲授 Python 程序设计的基础知识
与编程思维，帮助学生建立扎实的编程基础，能够独立完成小型软件项目。

**总学时**：42 学时（理论 20 + 实践 22）
**适用对象**：计算机相关专业大一学生、编程零基础学习者

---

## 章节安排

### 第 1 章：Python 基础语法（4 学时）
- 1.1 Python 语言简介与环境搭建
- 1.2 变量与基本数据类型（int, float, str, bool）
- 1.3 输入与输出（print, input）
- 1.4 运算符与表达式（算术、比较、逻辑）
- 1.5 字符串基本操作
- 1.6 类型转换

### 第 2 章：流程控制（6 学时）
- 2.1 条件判断（if / elif / else）
- 2.2 for 循环与 range()
- 2.3 while 循环
- 2.4 break 与 continue
- 2.5 循环嵌套
- 2.6 综合练习

### 第 3 章：函数与模块（6 学时）
- 3.1 函数定义与调用
- 3.2 参数传递（位置参数、默认参数、关键字参数）
- 3.3 返回值
- 3.4 变量的作用域（局部变量 vs 全局变量）
- 3.5 模块的导入与使用
- 3.6 常用内置函数（len, range, type 等）
- 3.7 Lambda 表达式简介

### 第 4 章：数据结构（8 学时）
- 4.1 列表（创建、索引、切片、常用方法）
- 4.2 元组（不可变序列）
- 4.3 字典（键值对、增删改查）
- 4.4 集合（去重、集合运算）
- 4.5 列表推导式
- 4.6 嵌套数据结构
- 4.7 综合练习

### 第 5 章：面向对象编程（8 学时）
- 5.1 面向对象思想概述
- 5.2 类的定义与对象的创建
- 5.3 __init__ 构造方法
- 5.4 实例属性与方法
- 5.5 继承与多态
- 5.6 魔法方法（__str__, __len__ 等）
- 5.7 异常处理（try/except/finally）

### 第 6 章：综合项目实战（10 学时）
- 6.1 文件读写操作
- 6.2 常用标准库（os, datetime, random）
- 6.3 第三方库的安装与使用（pip）
- 6.4 项目实战 1：学生成绩管理系统
- 6.5 项目实战 2：简易图书管理系统
- 6.6 代码调试技巧
- 6.7 代码规范与注释

---

## 学习路线图

```
第1章 基础语法 ──→ 第2章 流程控制 ──→ 第3章 函数模块
                                           ↓
第6章 项目实战 ←── 第5章 面向对象 ←── 第4章 数据结构
```

## 推荐学习方法
1. **边学边练**：每学一个知识点立即写代码验证
2. **循序渐进**：不要跳章节，基础不牢后面会越来越吃力
3. **多读代码**：阅读优秀的 Python 代码提升编程思维
4. **做项目**：学完每章尝试做一个小项目巩固知识
